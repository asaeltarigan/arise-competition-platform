ARISE 2026 — Datasets

Download the competition data. All submissions use the same test set.

🟢 Explorer — Basic ML (20%)

Titanic — classic tabular survival classification (712 train / 179 test rows, 10 features incl. name/ticket/cabin). Missing values + free-text columns are intentional — preprocessing and feature engineering are part of the task. The answer key is never included in downloads.

Download Explorer dataset (ZIP) 📓 Starter notebook
🔵 Innovator — Advanced ML (30%)

Dry Bean — 7-class seed classification from image-derived measurements (10,888 train / 2,723 test rows, 16 numeric features). Made for ensembles: Random Forest, XGBoost / LightGBM.

Download Innovator dataset (ZIP)
🟣 Master — Advanced ML (50%)

APS Failure at Scania Trucks — rare-event classification (48,000 train / 12,000 test rows, 170 anonymized features, ~1.7% positive). Imbalanced + heavy missing data — scored on F1 of the positive class, not accuracy. XGBoost/LightGBM, class imbalance handling, and threshold tuning are the game.

Download Master dataset (ZIP)

How submissions work
  1. Download the dataset above — use exactly the test.csv provided.
  2. Train on train.csv (or train/ + labels.csv for Master).
  3. Predict the label for every row in test.csv.
  4. Upload submission.csv (columns: id,prediction) on the submission portal.
